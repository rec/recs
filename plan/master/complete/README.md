# Master-plan archive policy

The master documents are mixed-status design references, not individual tasks.
Their remaining proposals do not make their implemented profiles unfinished.
Use [the active index](../../README.md), implemented format documentation, and
named checkpoint commits to distinguish completed work from proposals.

This directory has no archived implementation plans at present. Move a plan
here only when it is wholly historical, label its date and replacement, and
update incoming links. Do not move a living reference merely because one
milestone is complete.
