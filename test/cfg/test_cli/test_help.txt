  🎙 recs: The Universal Recorder 🎙
=============================================

Why should there be a record button at all?

I wanted to digitize a huge number of cassettes and LPs, so I wanted a program that ran in the background and recorded everything except quiet.

Nothing like that existed so I wrote it.  Free, open-source, configurable.

Full documentation here: https://github.com/rec/recs

With no subcommand, recs starts recording. sessions ROOT lists recordings; session COMMAND manages one recording; record check PATH validates a recording document and its media.

control pause/resume affect capture; control stop/continue affect playback. project manages saved recording projects; --profiles loads per-device JSON defaults.

readiness inspects a project or configuration without recording; preflight checks a running daemon.

Send one command to a running recs instance.

 options
 ------------------------------------------------------------------------------------------------

 subcommands

    - disk
    - devices
    - capabilities
    - mutable
    - get
    - set
    - mark

    - play             Play a recorded session, temporarily pausing capture if it is active.
    - stop             Stop playback; restore capture only if playback owned the capture pause.
    - pause-playback   Pause playback without resuming capture.
    - continue         Continue paused playback, not capture.
    - jump
    - jump-session
    - resume           Resume capture, first stopping any active playback.
    - calibrate
    - card-replace
    - reload-profiles  Reload per-device JSON defaults from --profiles, not a recording project.
    - project-switch   Switch mutable configuration to a named project or the default workspace.
    - musician-add
    - musician-list
    - musician-edit
    - musician-delete
    - musician-assign
    - musician-remove

$ recs session --help
usage: recs session [-h] {show,quality,markers,extract,handoff,recover,recover-scan,finalize,export-midi,migrate,export}

Inspect or manage one session. Use recs sessions ROOT to list sessions.

 options
 ----------------------------------------------------------------------------------------------------------------------
  -h, --help        show this help message and exit

 subcommands
 ----------------------------------------------------------------------------------------------------------------------
  (required)
    - show          Inspect one finalized recording session.
    - quality       Report one recording document's evidence; audio decoding is opt-in.

                    Frame positions are source-local, half-open ranges, not cross-device alignment. Near-full-scale
                    advisories are not proof of clipping. No quietness verdicts.
    - markers       List numbered markers and their available source-frame evidence.
    - extract       Preview marker extraction; supply --destination to render a new session.

                    Use numbers from session markers, not labels. Select one capture clock. Without --end-marker,
                    lead/tail surround --start-marker. Durations are seconds. Historical unpositioned markers are
                    rejected, never mapped from wall time.
    - handoff       Preview aligned tracks from one sealed segment; --destination writes the bundle.

                    Frame bounds are half-open on one capture clock. No resampling or alignment between independent
                    clocks is inferred. Output is 32-bit float WAV plus JSON.
    - recover       Preview recovery of a stopped version 4 capture; --destination creates a copy.

                    Audio is fully decoded for verification. Unfinished readable audio is retained as unplaced assets,
                    not aligned tracks. No original files are changed.
    - recover-scan  Discover unfinished session records below ROOT once.
    - finalize
    - export-midi
    - migrate
    - export

usage: recs sessions [-h] [OPTIONS] [PATH]

Search recording documents and journals without decoding media.

Filters combine with AND. Text matching is case-insensitive substring matching. Results use path order; dates use the calendar date as recorded, not file times.

 positional arguments
 ------------------------------------------------------------------------------------------------------------------
  [PATH]                root (default: .)

 options
 ------------------------------------------------------------------------------------------------------------------
  -h, --help            show this help message and exit
  --json, --no-json     (default: False)
  --since {None}|YYYY-MM-DD
                        Inclusive capture date (YYYY-MM-DD); unknown dates do not match. (default: None)
  --before {None}|YYYY-MM-DD
                        Exclusive capture date (YYYY-MM-DD); unknown dates do not match. (default: None)
  --source {None}|STR   Source name or identity, including event sources. (default: None)
  --track {None}|STR    Source-qualified audio track name. (default: None)
  --marker {None}|STR   Journal marker label or pressed key. (default: None)
  --media {None,audio,midi,osc,key,ump,events}
                        (default: None)
  --incomplete, --no-incomplete
                        Only open recordings or recordings with unresolved audio placement. (default: False)
  --warning {None}|STR  Warning/diagnostic text; an empty string matches any warning. (default: None)
  --limit INT           Maximum matching sessions returned; unreadable entries still report errors. (default: 100)
