$ recs session --help
usage: recs session [-h] {show,quality,markers,extract,handoff,recover,recover-scan,finalize,export-midi,migrate,export}

Inspect or manage one session. Use recs sessions ROOT to list sessions.

 options
 ----------------------------------------------------------------------------------------------------------------------
  -h, --help        show this help message and exit

 subcommands
 ----------------------------------------------------------------------------------------------------------------------
  (required)
    - show          Inspect one finalized recording session.
    - quality       Report one recording document's evidence; audio decoding is opt-in.

                    Frame positions are source-local, half-open ranges, not cross-device alignment. Near-full-scale
                    advisories are not proof of clipping. No quietness verdicts.
    - markers       List numbered markers and their available source-frame evidence.
    - extract       Preview marker extraction; supply --destination to render a new session.

                    Use numbers from session markers, not labels. Select one capture clock. Without --end-marker,
                    lead/tail surround --start-marker. Durations are seconds. Historical unpositioned markers are
                    rejected, never mapped from wall time.
    - handoff       Preview aligned tracks from one sealed segment; --destination writes the bundle.

                    Frame bounds are half-open on one capture clock. No resampling or alignment between independent
                    clocks is inferred. Output is 32-bit float WAV plus JSON.
    - recover       Preview recovery of a stopped version 4 capture; --destination creates a copy.

                    Audio is fully decoded for verification. Unfinished readable audio is retained as unplaced assets,
                    not aligned tracks. No original files are changed.
    - recover-scan  Discover unfinished session records below ROOT once.
    - finalize
    - export-midi
    - migrate
    - export

$ recs session quality --help
usage: recs session quality [-h] [OPTIONS] PATH

Report one recording document's evidence; audio decoding is opt-in.

Frame positions are source-local, half-open ranges, not cross-device alignment. Near-full-scale advisories are not proof of clipping. No quietness verdicts.

 positional arguments
 --------------------------------------------------------------------------------------------------------
  PATH               path (required)

 options
 --------------------------------------------------------------------------------------------------------
  -h, --help         show this help message and exit
  --json, --no-json  (default: False)
  --analyze-audio, --no-analyze-audio
                     (default: False)

 analysis options
 --------------------------------------------------------------------------------------------------------
  Limits apply independently to each fragment and its channels.
  --------------------------------------------------------------------------------------------------------
  --analysis.near-full-scale-dbfs FLOAT
                     Advisory threshold for absolute sample amplitude, in dBFS. (default: -0.1)
  --analysis.max-seconds FLOAT
                     Analyze at most this prefix of each fragment, in seconds. (default: 60)
  --analysis.max-runs INT
                     Retain at most this many run ranges per channel; count omitted runs. (default: 100)
