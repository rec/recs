$ recs control --help
usage: recs control [-h] {instances,status,disk,devices,capabilities,mutable,get,set,mark,pause,play,stop,pause-playback,continue,jump,jump-session,resume,calibrate,card-replace,reload-profiles,project-switch,musician-add,musician-list,musician-edit,musician-delete,musician-assign,musician-remove}

Send one command to a running recs instance.

 options
 ------------------------------------------------------------------------------------------------
  -h, --help           show this help message and exit

 subcommands
 ------------------------------------------------------------------------------------------------
  (required)
    - instances        List running instances without selecting a target.
    - status
    - disk
    - devices
    - capabilities
    - mutable
    - get
    - set
    - mark
    - pause            Pause capture and release input devices; this is not a playback pause.
    - play             Play a recorded session, temporarily pausing capture if it is active.
    - stop             Stop playback; restore capture only if playback owned the capture pause.
    - pause-playback   Pause playback without resuming capture.
    - continue         Continue paused playback, not capture.
    - jump
    - jump-session
    - resume           Resume capture, first stopping any active playback.
    - calibrate        Calibrate all tracks, or selected channels from one source.
    - card-replace
    - reload-profiles  Reload per-device JSON defaults from --profiles, not a recording project.
    - project-switch   Switch mutable configuration to a named project or the default workspace.
    - musician-add
    - musician-list
    - musician-edit
    - musician-delete
    - musician-assign
    - musician-remove
