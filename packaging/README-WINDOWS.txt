Recs for Windows
================

Version: <version>

This build is unsigned. Windows or antivirus software may warn before running it.

How to run Recs:

1. Right-click Recs-<version>-Windows.zip and choose "Extract All...".
2. Open the extracted Recs folder.
3. Double-click Recs.exe.

Do not move Recs.exe out of the folder. It needs the files next to it.

Recs needs permission to use your microphone or audio input devices. If Windows
asks for permission, allow it.

If antivirus software quarantines Recs, restore it only if you trust that you got
the file from the official Recs GitHub release. Some antivirus tools flag
unsigned PyInstaller applications even when they are harmless.
