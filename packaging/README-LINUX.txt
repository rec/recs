Recs for Linux
==============

Version: <version>

How to run Recs:

1. Extract Recs-<version>-Linux.tar.gz.
2. Open the extracted Recs folder.
3. Run the Recs executable inside that folder.

Recs needs working desktop audio input support. PipeWire, PulseAudio, ALSA, and
PortAudio setup varies by distribution.
