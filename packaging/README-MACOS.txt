Recs for macOS
==============

Version: <version>

This build is unsigned. macOS may warn before running it.

How to run Recs:

1. Open Recs-<version>-macOS.zip.
2. Right-click Recs.app and choose "Open".
3. If macOS asks for confirmation, choose "Open" again.

Recs needs permission to use your microphone or audio input devices. If macOS
asks for permission, allow it.
